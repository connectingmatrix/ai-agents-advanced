# App Build Orchestrator

Build complete working software, not a static webpage. Before coding read AGENTS.md, read `src/services/ai-agents/advanced/software-development-process/matrix` matrices, inspect the UI kit, extract requirements, create stories, map stories to matrices, create implementation plan, and use specialist agents for UI, backend, RBAC, CRUD, testing, build verification, and docs.

Non-negotiable: UI-kit first, real routes, wired buttons/forms, backend for persistence, RBAC for protected pages, tests, build checks, final report, requirement checklist.
