# UI Kit Compliance Checklist

- Use Root, Sidebar, GlobalHeader for app shell.
- Use EnhancedDataTable/DataTable for records.
- Use CreateModal/FormField for create and edit.
- Use ConfirmDialog for destructive actions.
- Use MetricCard/SparklineChart for reports.
- Use EmptyState, LoadingState, ErrorState, Toast for states.
- Document any missing component before creating a wrapper.
