# Definition Of Done

- Requirements, stories, acceptance criteria, and assumptions exist.
- UI-kit component mapping exists for every screen.
- Route/RBAC, CRUD, backend contract, state, test, and value-score matrices exist.
- CRUD UI is wired to API client and backend contract.
- Admin/protected actions have frontend and backend guards.
- Loading, empty, error, unauthorized, forbidden, success, offline, and not-found states are covered.
- Tests and build commands were attempted and documented.
- Final report and requirement completion checklist exist.
