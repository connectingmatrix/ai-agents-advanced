# Full-Stack Agent Subagents

The orchestrator uses these specialist roles for large app builds:

1. Requirement Analyst Agent
2. UI Kit Matrix Agent
3. Product Story Agent
4. Feature Pattern Mapping Agent
5. Route/Auth/RBAC Agent
6. Data Model and ORM Agent
7. Backend Contract Agent
8. CRUD Factory Agent
9. Frontend Implementation Agent
10. Backend Implementation Agent
11. Integration Agent
12. State Coverage Agent
13. Test Authoring Agent
14. Security/RBAC Review Agent
15. Build and Runtime Verification Agent
16. Final QA Gatekeeper Agent
17. Documentation Agent

Each work packet must include lifecycle step, inputs, required outputs, matrix references, memory namespace, expected artifact paths, and verification status.
